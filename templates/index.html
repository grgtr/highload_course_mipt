Использование API калькулятора

Вы можете использовать API этого калькулятора для расчёта числа судьбы с помощью командной строки (bash) или Python.

Для этого выполните POST-запрос по URL: /api/calculate с заголовком Content-Type: application/json и телом запроса в формате JSON, содержащим поле dob с датой рождения в формате ГГГГ-ММ-ДД.

Пример использования в bash (curl):

curl -X POST -H "Content-Type: application/json" -d '{"dob": "1990-01-01"}' http://localhost:8080/api/calculate

Пример использования в Python (requests):

import requests

url = "http://localhost:8080/api/calculate"
data = {"dob": "1990-01-01"}
response = requests.post(url, json=data)
print(response.json())
